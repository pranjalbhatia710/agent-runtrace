## X draft

I built `agent-runtrace`: a local trace viewer for AI agent runs.

Agents are painful to debug because the evidence is split across prompts, tool calls, shell output, file edits, and retries.

This records a run to JSONL and opens a standalone HTML timeline.

Think Playwright Trace Viewer for AI agents.

Repo: https://github.com/pranjalbhatia710/agent-runtrace

## LinkedIn draft

I started a small OSS project around a problem I keep seeing in AI agent tooling: debugging agent runs is still too messy.

`agent-runtrace` records prompts, tool calls, shell commands, errors, and file diffs into a local trace, then opens a standalone HTML viewer.

The goal is simple: make agent failures inspectable and shareable instead of buried in logs.

Repo: https://github.com/pranjalbhatia710/agent-runtrace
